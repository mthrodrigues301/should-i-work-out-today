# Should I Work Out Today?

Um site motivacional inspirado na mecânica simples do shouldideploy.today: a resposta é sempre **SIM**.

Disponível em português, inglês e espanhol. O idioma e o tema escolhidos ficam salvos no navegador.

## Rodar localmente

Abra `index.html` diretamente no navegador ou inicie qualquer servidor estático nesta pasta.

Não há dependências, build ou instalação.
